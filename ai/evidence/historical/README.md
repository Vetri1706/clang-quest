# Historical framework evidence

These reports describe earlier runs in the original separate framework. They are preserved for context, not presented as the current relocated-checkpoint evaluation. Absolute artifact location values were normalized to framework-relative paths; embedded settings/source hashes still describe the original run. The transformations are recorded in `NORMALIZATION.json`.

Current evidence is in [reports/ai](../../../reports/ai/). In particular, the earlier `cpp_evaluation.json` used an older pretraining checkpoint and must not be compared with the bundled hardened DPO checkpoint as a controlled before/after experiment.
